# A股板块轮动分析

## ⚠️ Walk-Forward 验证结论（2020-2024数据）

**固定阈值在A股几乎无效**（2020-2024数据验证）：

| 阈值 | 问题 |
|------|------|
| 冰点<5 | **全年从未触发**（4年数据min=8）|
| 轮动5-9 | 仅2020年有1天 |
| 主升浪>=20 | 2022熊市仍有99.6%天数在此状态 |

A股涨停家数的绝对值不能直接判断情绪，必须用**相对变化**。

**有效信号（经验证）**：
- 涨停家数**相对变化**（较5日均线/20日均线）是有效信号
- 涨停家数**从低位回升**是看多信号
- 涨停家数**从高位骤降**（如从>100骤降至<30）是退潮信号

---

## 修正后的情绪周期定义

| 状态 | 新定义 | 仓位建议 |
|------|--------|---------|
| 主升浪 | 涨停家数 >> 20日均线，且北向净流入 | 80-100% |
| 轮动期 | 涨停家数在20日均线附近波动 | 40-60% |
| 退潮期 | 涨停家数从高位骤降（>30%降幅） | 0-20% |
| 冰点 | 涨停家数 << 20日均线（如<均线×30%） | 空仓 |

## 状态转换规则（修正版）

```
冰点 → 轮动期：涨停家数从低位回升，突破20日均线
冰点 → 主升浪：涨停家数突破20日均线×2 且 北向净流入
轮动期 → 主升浪：主线成交额占比>均值×2.0 且 ≥5只连板
轮动期 → 退潮期：主线涨停家数连续2日下降>30%
主升浪 → 退潮期：连续2日炸板率上升 或 北向净流出>20亿/日
退潮期 → 冰点：涨停家数<均线×30%
```

## 注意事项

- 概念板块是动态增删的，只能用于近1-2年回测
- 申万一级行业可用于5年以上长周期回测
- ⚠️ 固定阈值（5家/10家/20家）经walk-forward验证无效，**改用相对变化**
- ⚠️ 所有阈值均未经严格walk-forward验证，绩效打折扣
